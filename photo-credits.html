PantryPal uses recipe-specific food photography. It checks TheMealDB first because the photo is attached to a complete meal record with ingredients and instructions, then uses openly licensed media sources only when no sufficiently close TheMealDB match exists. Source information is saved with each resolved photo.

How this works: PantryPal validates recipe names, important ingredients, and the primary food type before accepting a photo. TheMealDB is searched first. Wikimedia Commons and Openverse are fallback sources. If no candidate is trustworthy, PantryPal keeps a neutral local fallback rather than showing the wrong food.

Recipe data: the 6,500 built-in recipes in this version come from the project recipe dataset so the titles, ingredient lists, and cooking steps are real recipe records instead of generated combinations.
